# Australian Business Finder 0.4.0 — bounded candidate evaluation

**Status: development evidence, 9 October 2026 (Australia/Perth).** This report tests a revised decisive-claim procedure against earlier failure classes and one new task. It does not establish that the skill outperforms an ordinary agent, independently verifies businesses, or works across every host and model. The [0.3.0 evaluation](EVALUATION.md) remains the historical fixed point and records negative results rather than being overwritten.

## Change under test

The revision separates broad candidate discovery from precise source checking. It requires opened page evidence connecting the same business to the requested offering and place, a full-page check plus one bounded safe recovery before declaring a decisive fact absent, and exact copying or omission of optional contacts. Detailed examples live in the package's `references/claim-checking.md`; no scraper, dataset, contact action or automated business-verification claim was added.

## Method and limits

- Fresh, **serial** one-shot Hermes sessions used `gpt-6-sol-900k`, `web,browser` tools, `--ignore-rules`, and the candidate `SKILL.md` **inlined with its reference in the prompt**. This exercised its instructions, **not a clean GitHub installation, natural skill activation or a blind trial**. The installed older skill was not preloaded. Each prompt prohibited reading old evaluation reports and contacting a business.
- Prompts requested no more than three searches, approximately five page opens and one safe targeted recovery. This was guidance, not a hard-enforced tool cap; some runs opened more pages. `web_extract` failed because its configured backend was search-only; browser pages sometimes recovered. Search results, access challenges and model decisions differed from the older trial. Raw runtime traces remain private because they contain profile/runtime context; the prompts and adjudication below are public.
- R1 was first run with the new claim reference and returned **0/2**. After observing that over-specific search queries hid candidates, the discovery instruction was revised to start broadly and check attributes on opened pages; **only the revised R1 result** is reported below. The first R3 attempt produced an answer but exited **1** after exhausting its iteration cap; it is not counted. R3 was rerun with a higher turn ceiling and exited **0**. These cases are development tests, not untouched holdouts.
- Scores below mean candidates **presented with opened first-party pages** supporting an attributed identity × offering × place claim as audited from the tool trace. A website claim is not independent proof of current trading, premises, stock or service. Counts are not national recall rates. Static package tests passed separately; they do not score answer quality.

H1 is now development data because its result informed the revision; a future release comparison needs new untouched cases.

## Exact-package install and host smoke

The candidate at commit [`e8736e35`](https://github.com/JakeMarchin-Vincent/skills/commit/e8736e35ee6372a93867f59eac30765b8ae5c6b5) was installed from its raw `SKILL.md` URL into an isolated Hermes home. The community scanner returned **SAFE / ALLOWED**; installed `SKILL.md`, `references/claim-checking.md` and `references/LICENSE.md` matched that commit byte-for-byte. This tests package retrieval and referenced-file distribution, not behavioural correctness.

The same pinned package was then installed into MEWY's `research/aus-business-finder-mv` profile skill and explicitly preloaded in new CLI sessions. A Cairns commercial kitchen-exhaust lookup exited **0**, opened [Lotus Commercial's Cairns page](https://www.lotuscommercial.com.au/cairns/), and attributed its Cairns service-area and copied contact details to that page. An Orange termite-inspection/street-address lookup exited **0**, loaded the package's `claim-checking.md` through `skill_view`, and returned a bounded **no sourced match** rather than treating a PO Box or general locality as a street address. A separate *non-preloaded* Newcastle mobile-forklift-repair request exited **0**; the agent naturally loaded both the skill and its reference with `skill_view` and opened first-party pages for [Our Town Forklift Service](https://www.ourtownforkliftservice.com/) and [Hunter MLA](https://www.mlaholdings.com.au/forklift-service-repair/forklift-service-repair-newcastle/). **Citation gap:** its Gateshead-workshop detail came from a separately opened [Our Town-associated page](https://forkliftnewcastle.com.au/), but the answer cited only the main Our Town URL for that candidate. The source-linked core Newcastle service-area claim remained supported; the workshop detail was not properly cited in the reply. The procedure now calls for each material detail's own opened URL or its omission. These are site claims, not independent proof of operation or coverage. No business was contacted. These are installed-host smoke checks, **not** a clean credential-free home live model trial or a controlled comparison.

The configured `web_search` and `web_extract` provider in those profile runs was unavailable (`ddgs` not registered). The agent used a browser fallback; therefore the Orange no-match cannot be interpreted as a complete search. A second unprompted Newcastle run exited **0** but did **not** load the skill through `skill_view`; its useful answer cannot be attributed to the package. The description was sharpened to mention Australian business lookups by type, place or name. Natural activation is stochastic and not yet established as reliable. Source access and host configuration remain material limits.

## Publication boundary and next check

A public beta may be described as a **source-linked candidate finder with explicit limits**, not a verified business directory or a proven improvement over unskilled research. The branch package has been installed and smoke-tested in the configured profile, but the merged default-branch identifier still needs exact read-back after release. Before promoting broader performance claims: compare on a new, matched, separately held case set; record failures and access limits. No business was contacted in these tests.
